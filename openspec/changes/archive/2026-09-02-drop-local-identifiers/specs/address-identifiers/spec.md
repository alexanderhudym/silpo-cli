### Requirement: A saved address is recorded by its remote identity

**Reason**: No entity is recorded. A saved address prints whatever its payload names it by.

**Migration**: None. An address still reaches the cart as coordinates, never as an identifier.

### Requirement: No argument takes a saved address

**Reason**: Still true, but it is no longer a statement about a numbering the CLI issues. It belongs
with what the saved address listing prints, and is restated there.

**Migration**: None.
